# Travel Gallery Images

Add your travel photos to this directory.

## Usage

To add photos to the gallery, edit the `travelImages` array in `gallery.html`:

```javascript
const travelImages = [
    {
        src: 'res/images/travel/yourphoto.jpg',
        description: 'One sentence describing the moment or experience',
        location: 'City/POI, Country'
    },
    // add more images...
];
```

## Recommendations

- Use optimized JPG images (recommended max width: 1200px)
- Keep file sizes reasonable (< 500KB per image)
- Use descriptive filenames (e.g., `patagonia-hitchhiking.jpg`)
